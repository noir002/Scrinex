Run it on your own machine

This live demo is one server's snapshot of one repo — it can't reach your filesystem, and nothing you do here touches your own projects. To actually use nex on your own files, grab the portable bundle below (pure Python stdlib, nothing to install):

❯unzip nex-portable.zip && cd nex-portable
❯python3 nex.py init
❯python3 nex.py add .
❯python3 nex.py commit -m "first commit"

Architectural Integrity

Every command maps to a real, working piece of the object model underneath — nothing here is a mock.

Merkle Object Store

Blobs, trees, and commits are content-addressed by SHA-1 hash. Change one file and the hash changes all the way up to the root — identical subtrees are deduplicated automatically.

CLI-First Workflow

The same verbs you already know — init, add, commit, log, branch, checkout — implemented from scratch, no wrapping of the real git binary underneath.

❯ nex commit -m "core object model"

Local-First Push

Push targets a path on disk standing in for a remote — same copy-missing-objects mechanics as a real remote, no server or account required to try it.
